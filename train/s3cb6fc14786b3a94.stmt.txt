Problem A: Clock 
 Problem 

 
がっちょ君はお気に入りの時計を持っている。ある日時計の長針が取れてしまい、どこかへなくしてしまった。しかし、がっちょ君はその時計を使い続けたいため短針だけで時刻を読み取りたいと考えている。
 

 
短針の情報 &theta; に対する時刻(時 h 、分 m )を出力せよ。時計はいわゆるアナログ時計で、1から12の数が等間隔に時計回りに昇順に並んでいるものである。 
 


 Input 
 入力は以下の形式で与えられる。 
 
 &theta; 
 

 
1行に短針の角度 &theta; を表す整数が度数法(degree)で与えられる。
短針が指す方向は、12時を指す方向を0度としたとき、時計回りに &theta; 度回転した方向である。
 

 Constraints 

 
 0 &le; &theta; &le; 359 
 



 Output 
 
 短針が与えられた角度をとる時の時刻を 
 h m 
 の形で1行に出力する。 
 
 時刻に午前午後の区別はないため0 &le; h &le; 11とする。 
 


 Sample Input 1 
 
0
 

 Sample Output 1 
 
0 0
 

 Sample Input 2 
 
45
 

 Sample Output 2 
 
1 30
 

 Sample Input 3 
 
100
 

 Sample Output 3 
 
3 20
